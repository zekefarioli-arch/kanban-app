# Kanban Board App

## Project Structure

- `index.html`: The main HTML file that includes CSS and JS files.
- `styles.css`: Contains styles for the Kanban board, including gradients and shadows.
- `script.js`: Contains JavaScript logic for drag-and-drop functionality and adding new cards.

## How to Run

1. **Install Dependencies**: Ensure you have Node.js installed on your machine.
2. **Navigate to Project Directory**: Open a terminal and navigate to the project directory.
3. **Install Packages**: Run `npm install` to install all dependencies.
4. **Start Development Server**: Run `npm start` to start the development server.
5. **Access Application**: Open a web browser and go to `http://localhost:3000` to view the Kanban board application.

## Testing

1. **Run Tests**: Use Jest to run tests by running `npm test`.
